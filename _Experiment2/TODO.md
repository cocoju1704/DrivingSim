## 2. SAGAT: 8칸 → 4구역 (있다/없다)
- 구역: 내 차선 전방 / 좌 사이드미러 / 우 사이드미러 / 룸미러
- 근거(논문용): A 결과 칸별 정답률로 "옆 칸은 우연 수준"임을 보이기, "TOR 때 필요한 옆 차선 정보는 미러로 얻는다"
- 정답 정의: 기하학적으로 (미러 = 옆 칸 뒤쪽의 차, 기존 규칙 유지), 좌후방 차가 사이드미러와 룸미러에 같이 보이는 경우 정리
- 스케줄러(`abc_schedule.py` Q): 4구역 기준으로 다시 짜기
  - 문항마다 있음/없음 기저율을 블록 전체에서 반반으로
  - 질문 시점에 애매한 구역(미러 가장자리, 구역 경계) 비우기
  - TOR 시점에 사각지대(옆 칸) 비우기 (사각지대는 측정 안 한다고 한계로 명시)
- 전방 문항: 천장 효과 우려 → "가까워지고 있나요?"(Level 2)로 바꿀지 결정
- 확신도 문항 유지 여부 결정
- 분석: 정답률 말고 hit/FA(d′), 미러 시선(mirror_aoi)과 미러 문항 정답의 대응(수렴 타당도)
