## 기기에서 확인 (앱 업데이트 때 한 번에)
- 배포: 영상 서버 노트북에 `mrbd-video/public/*`(app.js, style.css, index.html, sw.js) 복사 → 안경 Meta AI 앱에서 웹앱 연결 끊었다 다시(홈에 v17) → 폰 `python mrbd-video/phone_app/build.py --install --videos`(새 `스위스러시아_B.mp4` 포함) → 원격 서버 `media/`에 새 `스위스러시아_B.mp4`
- 안경 v17: 400 px 영상이 오른쪽 위에 맞게 나오는지, 휴대폰·HUD 블록에서 검은지, `video.muted`로 실제 음소거되는지
- 폰 v4: 세로 재생, 음소거, 마커(아래 "휴대폰 조건 화면 응시")
- PC 이어폰 영상 소리(`device_audio.py`): 입 모양과 맞는지(터널 경유면 `LEAD_S` 0.2 s 조정), TOR 경고음과 mixer 채널이 겹치지 않는지
- 블루투스 지연 한 번 재서 README에(`bt_latency.py`, README "소리")
- 이어폰을 끊었을 때 사전 점검 경고
- 빠른 재착용·블록 뒤 HUD 점검 전체 흐름(글래스 2 + Ray-Ban). 넓은 코받침·헤드 스트랩 시험
- HUD 11°: 첫 참가자에서 HUD 검증 점(`hud_gaze.json`)으로 글래스·HUD 두 화면을 같은 시선 좌표로 비교해 최종 크기 확인

## 결정할 것
- 채점 칸 좁히기: 질문 차는 이제 뒤 18–25 m, 앞 10–24 m. 채점 칸(`cell_dx_m` 뒤 15–45, 앞 5–35 m)은 그대로 둠
- 차량 소리가 합성음 같은 것: 소리 파일·설정은 `_Experiment`와 이미 같음. 차이는 자율주행 스로틀 변화 속도(`carla_base.AUTO_THROTTLE_RATE` 0.6, `_Experiment` 0.3)와 순항 속도. 0.3으로 하면 주행 거동·커브 프로파일(`abc_ego.py --log`)도 다시 해야 함
- 룸미러 10°는 1.8배 확대 상: 운전자가 거리감을 다르게 느끼는지 테스트 주행에서 보기
- 50 m 안 배경 차 밀도가 목표(5–7대)보다 낮음: 평균 3.0–4.1대
- A-Q2의 나온 장면은 야경을 피하느라 3 s 샷 하나(같은 노점이 11.5 s 이어짐, "5 s 이상·인물 위주" 규칙을 완화): 그대로 쓸지

## 휴대폰 조건 화면 응시 (폰 앱 v4 마커, 구현됨)
- 폰에 v4 설치(`python mrbd-video/phone_app/build.py --install --videos`) 뒤 확인: 네 모서리 마커가 화면에 다 들어오는지(둥근 모서리·노치에 안 잘리는지), 실제 한 변이 1.2–1.6 cm인지 자로 재기, 블록 폴더에 `phone_screen.json`이 생기는지
